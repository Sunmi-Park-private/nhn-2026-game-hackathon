## 2. 주제 해석

### 키워드 구성

본선은 **공통 주제어 1개 + 기능 키워드 2개**를 요구한다.
기능 키워드는 **추첨 1개 + 선택 1개**로 구성된다.

| 구분 | 키워드 | 주최 측 정의 |
|---|---|---|
| 공통 주제어 | **2026년** | — |
| 기능 키워드 (추첨) | **물리법칙** | 속도, 빛과 색, 중력 등 물리와 자연 법칙을 활용하는 축 |
| 기능 키워드 (선택) | **합체** | 둘 이상을 합쳐 새로운 것을 만드는 기능 |

### 2-1. 「2026년」 → 병오년, 붉은 말의 해

2026년은 병오년(丙午年), **붉은 말의 해**다. 근육질의 붉은말을 플레이어의 분신으로 세운다.
이 말은 마스코트가 아니라 **발사대 그 자체**다 — 화면 하단에서 위를 올려다보며 육각 타일을 던지는 자세가 조작의 전부이자 캐릭터의 정체성이다.

### 2-2. 「물리법칙」 → 판을 지배하는 법칙

정의에 제시된 세 가지 예시를 **전부** 사용한다.

| 정의의 예시 | 게임 안의 구현 |
|---|---|
| **속도** | 던진 타일의 발사 속도와 궤적. 조준선을 읽고 착탄 지점을 예측한다 |
| **중력** | 받침(앵커)을 잃은 타일 덩어리가 무너져 내리는 낙하 |
| **빛과 색** | **타일의 색 순서가 가시광선의 파장 순서다** (아래 2-4) |
| (추가) 반사 | 좌우 벽에서 입사각 = 반사각으로 튕기는 뱅크 샷 |

### 2-3. 「합체」 → 스펙트럼을 거슬러 오르는 승급

같은 색 육각 타일 셋이 맞닿으면 한 단계 위의 색으로 합쳐진다. 게임의 코어 동사이며,
**우리를 여는 유일한 수단**이다.

### 2-4. 두 키워드를 잇는 다리 — 색은 파장이다

```
빨강 700nm → 노랑 580 → 초록 530 → 파랑 470 → 보라 400nm
        파장이 짧아진다 = 에너지가 높아진다
```

승급 사슬의 색 순서는 임의로 고른 것이 아니라 **가시광선의 파장 순서**다.
합칠수록 파장이 짧아지고 에너지가 쌓인다. **보라를 넘어서면 사람 눈에 보이는 색이 없다** —
그래서 마지막 합체는 승급하지 못하고 축적된 에너지를 황금빛으로 터뜨린다.

> 이 해석은 제출용 수사가 아니다. 「최고 티어는 폭발한다」는 규칙이 임의적 설정이 아니라
> **필연**이 되므로, 플레이어에게 따로 설명할 필요가 없어진다.

**역할 분담:** 「물리법칙」은 *어떻게 움직이는가*, 「합체」는 *무엇이 일어나는가*를 맡는다.
두 키워드가 겹치지 않으면서 하나의 게임에서 필연적으로 이어진다.

## 3. 장르

**헥사 그리드 머지 슈터 (Hex-grid Merge Shooter)** — 두 장르의 교배.

| 출처 | 가져오는 것 |
|---|---|
| 버블 슈터 (Bust-a-Move 계열) | 하단 발사대에서 정적 그리드로 발사체를 쏘아 붙이는 조작 |
| 머지 / 티어업 (2048, Suika) | 같은 것끼리 만나면 상위 등급으로 **합쳐지는** 규칙 |

일반 버블 슈터는 같은 색 3개가 붙으면 *터진다*(pop). 본작은 *합쳐진다*(merge). **「합체」가 핵심 키워드이므로 후자가 코어다.**

## 4. 코어 루프

```
조준 → 발사 → 스냅 → 합체 판정 → 연쇄 → 낙하 → 구출 판정
  ↑                                                  ↓
  └────────────── 샷 잔량 있음 ──────────────────────┘
                          ↓ 목표 달성
                      스테이지 클리어 → 도감·목장 누적 → 다음 스테이지
```

한 스테이지는 **제한된 발사 횟수 안에 목표 마릿수를 구출**하면 클리어된다.

## 5. 규칙

### 5-1. 티어 사슬 (색 = 티어, 단일축)

```
🔴 빨강 → 🟡 노랑 → 🟢 초록 → 🔵 파랑 → 🟣 보라 → 🟠 황금
 T1        T2        T3        T4        T5        T6(최고)
```

색과 티어를 **하나의 축으로 통합**한다. 색×티어 2축으로 두면 타일 아트가 곱으로 늘어나고 판이 복잡해진다. 단일축이면 **아트 6종이면 끝**이고, 승급이 눈으로 즉시 읽힌다.

이 순서는 **가시광선의 파장 순서**다(§2-4). 합칠수록 파장이 짧아지고 에너지가 높아진다.

### 5-2. 발사 — 판에 남은 색에서 뽑는다

- 발사체의 색은 **현재 판에 놓여 있는 색 중에서만** 추첨된다. 판에 없는 색은 나오지 않는다
- 낮은 티어일수록 자주 나온다(대략 53 / 27 / 13 / 7 %). 빨강이 흔해야 판을 쌓아 올릴 수 있고, 상위 색도 두 발이면 모인다
- 쓸모없는 탄이 없으므로 **발사 제한이 곧 난이도**가 된다. 무엇을 쏠지가 아니라 어디에 붙일지가 실력이다

> **한때 「발사체는 항상 빨강」이었다.** 그러면 판의 노랑을 깨는 데 빨강 9발, 초록은 27발,
> 황금은 243발이 든다 — 비용이 3의 거듭제곱으로 늘어난다. 스테이지 발사 제한이 20~25발이라
> 초록 이상은 손댈 수 없었고, 케이지 앞을 비우는 유일한 수단인 합체가 성립하지 않아
> **구출 자체가 불가능했다.** 실제 플레이에서 발견해 되돌린 규칙이다.

### 5-3. 합체

1. 발사체가 충돌 후 가장 가까운 빈 셀에 **스냅**
2. 스냅 지점 기준 **같은 색 연결 성분**을 계산 (flood fill)
3. 크기가 **3 이상**이면 합체 — **착탄 지점에 상위 색 1개**가 남고 나머지는 소멸
4. 생성된 상위 색으로 **재판정** → 연쇄(cascade)
5. **황금 3개가 합체하면 광역 폭발** — 중심 기준 반경 1(6칸) + 자신 제거

보라 위로는 사람 눈에 보이는 색이 없다. 승급할 곳이 없으므로 축적된 에너지가 폭발로
방출된다 — 규칙이 아니라 **결과**라서 플레이어에게 설명이 필요 없다.

연쇄가 점수와 손맛의 원천이다.

### 5-4. 낙하 (부유 클러스터 드롭)

- **앵커 = 그리드 최상단 행 + 케이지 셀**
- 합체·폭발로 타일이 사라진 뒤 앵커와 연결이 끊긴 덩어리는 **낙하하며 획득 처리**된다
- 케이지가 앵커이므로 **케이지 주변 타일은 저절로 떨어지지 않는다** — 반드시 합체로 걷어내야 한다. 난이도가 여기서 발생한다

### 5-5. 케이지와 구출

- 케이지는 **가로 2셀을 점유하는 멀티셀 오브젝트**
- **비배치 셀** — 발사체가 충돌은 하되 스냅되지 않는다
- **구출 조건: 케이지에 인접한 모든 셀이 비었을 때**
- 구출 시 자물쇠가 열리고 동물이 튀어나온다 → 상단 목표 카운터 증가

규칙이 한 줄이라 별도 튜토리얼이 필요 없다.

### 5-6. 말굽 타일

보드 위의 갈색 말굽 육각. **합체에 참여하지 않는 중립 타일**이다.

말굽은 스스로 사라지지 않는다. 주변이 정리되어 **앵커와의 연결이 끊겼을 때 낙하 규칙(5-4)에 따라 떨어지며 획득**된다. 즉 말굽을 얻으려면 그 아래를 받치고 있는 타일들을 합체로 걷어내야 한다. 스테이지 종료 시 누적되며 「수집」 키워드를 담당한다.

### 5-7. 부스터 3종

| 부스터 | 효과 | 키워드 |
|---|---|---|
| 💣 **폭탄** | 다음 발사체가 폭탄이 되어 착탄 반경 1을 제거 | 분해 |
| 🌈 **레인보우** | 다음 발사체가 어떤 색과도 합체 성립 | 교환 |
| 🐴 **말굽** | **현재 발사체를 한 티어 승급** (빨강 → 노랑) | 합체·성장 |

> 말굽 부스터는 추첨에 기대지 않고 **원하는 색을 한 단계 끌어올리는** 수단이다. 판에서 뽑힌 색이 한 끗 모자랄 때 쓴다.

### 5-8. 실패 조건

**발사 횟수 제한(샷 리밋)만 사용한다.**
페일 라인·천장 하강은 넣지 않는다 — 규칙이 늘수록 학습 비용이 커지고, 주어진 시간에 밸런싱할 여유가 없다.

## 6. 스테이지

- 스테이지 데이터는 JSON으로 기술한다: 목표 마릿수 · 샷 리밋 · 케이지 배치 · 초기 타일 · 말굽 위치
- 초기 배치는 **가중 랜덤**으로 생성하되, **데드락 방지 보정**을 생성 단계에 넣는다 — 빨강 3개가 붙을 자리가 항상 존재해야 한다
- 클리어 후 곧바로 다음 스테이지로 이어진다 (연속 플레이)

## 7. 메타 레이어

```
타이틀 → 로비(목장) ⇄ 스테이지 셀렉트 → 퍼즐 판 → 구출 연출 → 다음 스테이지
            ↓
          도감
```

| 요소 | 내용 |
|---|---|
| **로비 (목장)** | 구출한 동물이 실제로 목장에 늘어난다. 시각적 보상 |
| **레벨** | 총 구출 수 기반. 로비 상단 게이지 |
| **도감** | 구출 / 미구출 동물 그리드 |
| **연속 플레이** | 클리어 시 다음 스테이지로 직행 |

### 구현하지 않는 것

미션 · 상점 · 재화(코인·젬) · 일일 보상 — 상용 F2P 메타 풀세트는 퍼즐 엔진보다 크다. **심사위원이 실제로 만질 범위**에 집중한다.

## 8. 아트 방향

- 카툰 스타일, 두꺼운 아웃라인, 채도 높은 원색
- 배경: 낮의 헛간 내부. 나무 프레임이 좌우 반사벽 역할을 겸한다
- 붉은말이 화면 하단에서 위를 올려다보며 타일을 던지는 자세 — 발사대가 곧 캐릭터
- **타일 아트 6종**(빨·노·초·파·보·황금) + 말굽 타일 + 부스터 아이콘 3종 + 케이지 + 동물

**제작 사양:** 육각 반지름 30px 기준 **셀 폭 52px**. 논리 해상도 430×800, 7열 배치.

## 9. AI 활용

인게임 런타임 LLM은 **사용하지 않는다.** 순수 규칙 게임이므로 억지 접목은 오히려 감점 요인이고, 오프라인 폴백·쿼터·지연이라는 시연 리스크만 늘어난다.

AI 활용은 **제작 과정 전체**로 증명한다:

- 게임 로직 소스코드 생성
- 이미지 에셋 생성
- 배경음악 생성
- 작업을 노드 스펙으로 분해해 에이전트에게 위임한 기록 → 그 모음이 곧 **에이전트 설계서**가 된다
