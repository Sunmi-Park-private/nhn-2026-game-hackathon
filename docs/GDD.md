## 2. 주제 해석

### 키워드 구성

본선은 **공통 주제어 1개 + 기능 키워드 2개**를 요구한다.
기능 키워드는 **추첨 1개 + 선택 1개**로 구성된다.

| 구분 | 키워드 | 주최 측 정의 |
|---|---|---|
| 공통 주제어 | **2026년** | — |
| 기능 키워드 (추첨) | **물리법칙** | 속도, 빛과 색, 중력 등 물리와 자연 법칙을 활용하는 축 |
| 기능 키워드 (선택) | **재선정 중** (§2-3) | — |

### 2-1. 「2026년」 → 병오년, 붉은 말의 해

2026년은 병오년(丙午年), **붉은 말의 해**다. 근육질의 붉은말을 플레이어의 분신으로 세운다.
이 말은 마스코트가 아니라 **발사대 그 자체**다 — 화면 하단에서 위를 올려다보며 육각 타일을 던지는 자세가 조작의 전부이자 캐릭터의 정체성이다.

### 2-2. 「물리법칙」 → 판을 지배하는 법칙

정의에 제시된 세 가지 예시를 **전부** 사용한다.

| 정의의 예시 | 게임 안의 구현 |
|---|---|
| **속도** | 던진 타일의 발사 속도와 궤적. 조준선을 읽고 착탄 지점을 예측한다 |
| **중력** | 받침(앵커)을 잃은 타일 덩어리가 무너져 내리는 낙하 |
| **빛과 색** | **타일의 색 순서가 가시광선의 파장 순서다** (아래 2-4) |
| (추가) 반사 | 좌우 벽에서 입사각 = 반사각으로 튕기는 뱅크 샷 |

### 2-3. 기능 키워드(선택) — **재선정이 필요하다**

> ⚠️ **이 절은 코드와 어긋나 있다.** 선택 키워드로 「합체」를 잡고 승급 규칙을 만들었으나,
> 실제 플레이에서 **그 규칙 때문에 구출이 불가능**하다는 것이 드러나 승급을 걷어냈다(§5-3).
> 지금 규칙에 합체는 없다. 아래 후보 중에서 다시 고르고 이 절을 다시 쓴다.

| 후보 | 지금 규칙 안에서의 근거 |
|---|---|
| **분해** | 코어 동사 그 자체다. 같은 색 덩어리를 **분해해** 케이지 둘레를 걷어낸다 |
| **수집** | 말굽이 낙하로 회수되어 누적된다. 구출한 동물이 목장·도감에 쌓인다 |
| **예측** | 조준선이 벽 반사까지 미리 그린다. 어디에 붙을지 읽고 쏘는 것이 실력이다 |
| **제한** | 실패 조건이 샷 리밋 하나뿐이다. 발사 한 발의 값이 곧 난이도다 |

**분해**가 가장 곧다 — 코어 동사와 구출 조건이 한 문장으로 이어진다.

### 2-4. 색은 왜 이 순서인가

```
빨강 700nm → 노랑 580 → 초록 530 → 파랑 470 → 보라 400nm
```

6색의 배열은 임의로 고른 것이 아니라 **가시광선의 파장 순서**다. 규칙이 이 순서에
걸려 있지는 않지만, 색이 무작위가 아니라 한 줄로 늘어선 스펙트럼이라는 것이
아트·UI·발사체 추첨 가중치를 모두 같은 축 위에 올려놓는다.

**역할 분담:** 「물리법칙」은 *어떻게 움직이는가*(속도·중력·반사·빛), 선택 키워드는
*무엇이 일어나는가*를 맡는다.

```
조준 → 발사 → 스냅 → 색 판정 → 터짐 → 낙하 → 구출 판정
  ↑                                                  ↓
  └────────────── 샷 잔량 있음 ──────────────────────┘
```

## 5. 규칙

### 5-1. 색 (단일축, 6종)

```
🔴 빨강   🟡 노랑   🟢 초록   🔵 파랑   🟣 보라   🟠 황금
```

색은 등급이 아니라 **서로 구별되는 6가지**다. 색×등급 2축으로 두면 타일 아트가
곱으로 늘어나고 판이 복잡해진다. 단일축이면 **아트 6종이면 끝**이다.

배열 순서는 가시광선의 파장 순서를 그대로 쓴다. 규칙이 걸려 있지는 않지만,
색이 무작위가 아니라 **한 줄로 늘어선 스펙트럼**이라는 것이 아트와 UI를 일관되게 만든다.

### 5-2. 발사 — 판에 남은 색에서 뽑는다

- 발사체의 색은 **현재 판에 놓여 있는 색 중에서만** 추첨된다. 판에 없는 색은 나오지 않는다
- 낮은 티어일수록 자주 나온다(대략 53 / 27 / 13 / 7 %). 빨강이 흔해야 판을 쌓아 올릴 수 있고, 상위 색도 두 발이면 모인다
- 쓸모없는 탄이 없으므로 **발사 제한이 곧 난이도**가 된다. 무엇을 쏠지가 아니라 어디에 붙일지가 실력이다

> **한때 「발사체는 항상 빨강」이었다.** 그러면 판의 노랑을 깨는 데 빨강 9발, 초록은 27발,
> 황금은 243발이 든다 — 비용이 3의 거듭제곱으로 늘어난다. 스테이지 발사 제한이 20~25발이라
> 초록 이상은 손댈 수 없었고, 케이지 앞을 비우는 유일한 수단인 합체가 성립하지 않아
> **구출 자체가 불가능했다.** 실제 플레이에서 발견해 되돌린 규칙이다.

### 5-3. 터뜨리기

1. 발사체가 충돌 후 가장 가까운 빈 셀에 **스냅**
2. 스냅 지점 기준 **같은 색 연결 성분**을 계산 (flood fill)
3. 크기가 **3 이상**이면 그 덩어리가 **전부 사라진다** — 착탄 지점도 함께 비운다
4. 받침을 잃은 덩어리가 있으면 낙하한다(§5-4). 연쇄는 여기서 나온다

> **한때는 「합체」였다.** 셋이 붙으면 착탄 지점에 한 단계 위 색을 남기고 나머지를
> 지웠다. 3칸이 1칸으로 줄기는 해도 **그 자리가 절대 비지 않는다.** 구출은 케이지
> 둘레 12칸이 전부 비어야 성립하는데, 합체할 때마다 하나가 남으니 빨강에서 황금까지
> 다섯 단계를 올려 터뜨리는 길 말고는 판을 비울 방법이 없었다.
> 승급을 걷어내자 **코어 동사 하나로 구출까지 곧장 이어진다.**
>
> 이 변경으로 **기능 키워드 「합체」가 규칙에서 사라졌다.** §2-3 참조.

### 5-4. 낙하 (부유 클러스터 드롭)

- **앵커 = 그리드 최상단 행 + 케이지 셀**
- 타일이 터져 사라진 뒤 앵커와 연결이 끊긴 덩어리는 **낙하하며 획득 처리**된다
- 케이지가 앵커이므로 **케이지 둘레 타일은 저절로 떨어지지 않는다** — 반드시 터뜨려 걷어내야 한다. 난이도가 여기서 발생한다

### 5-5. 케이지와 구출

- 케이지는 **육각 덩어리를 점유하는 멀티셀 오브젝트**다. 중심 칸과 그 이웃 6칸, 합쳐 7칸을 먹는다
- 화면에는 칸마다 쪼개 그리지 않고 **덩어리 전체를 덮는 큰 육각 창살 한 장**으로 그린다.
  그 바깥 둘레(반지름 2, 12칸)를 1칸짜리 육각 타일이 감싼다 — 큰 육각을 작은 육각이 두르는 구조가 판의 얼굴이다
- **비배치 셀** — 발사체가 충돌은 하되 스냅되지 않는다
- **구출 조건: 케이지에 인접한 모든 셀이 비었을 때** — 즉 둘레 12칸을 전부 걷어내야 한다
- 구출 시 자물쇠가 열리고 동물이 튀어나온다 → 상단 목표 카운터 증가

규칙이 한 줄이라 별도 튜토리얼이 필요 없다.

### 5-6. 말굽 타일

보드 위의 갈색 말굽 육각. **색 판정에 참여하지 않는 중립 타일**이다.

말굽은 스스로 사라지지 않는다. 주변이 정리되어 **앵커와의 연결이 끊겼을 때 낙하 규칙(5-4)에 따라 떨어지며 획득**된다. 즉 말굽을 얻으려면 그 아래를 받치고 있는 타일들을 터뜨려 걷어내야 한다. 스테이지 종료 시 누적되며 「수집」 키워드를 담당한다.

### 5-7. 부스터 3종

| 부스터 | 효과 | 키워드 |
|---|---|---|
| 💣 **폭탄** | 다음 발사체가 폭탄이 되어 착탄 반경 1을 제거 | 분해 |
| 🌈 **레인보우** | 다음 발사체가 어떤 색과도 맞는 것으로 처리 | 교환 |
| 🐴 **말굽** | **현재 발사체를 다음 색으로 교체** | 교환 |

> 말굽 부스터는 추첨에 기대지 않고 **원하는 색을 직접 고르는** 수단이다. 판에서 뽑힌 색이 한 끗 모자랄 때 쓴다.

### 5-8. 실패 조건

**발사 횟수 제한(샷 리밋)만 사용한다.**
페일 라인·천장 하강은 넣지 않는다 — 규칙이 늘수록 학습 비용이 커지고, 주어진 시간에 밸런싱할 여유가 없다.

## 6. 스테이지

- 스테이지 데이터는 JSON으로 기술한다: 목표 마릿수 · 샷 리밋 · 케이지 배치 · 초기 타일 · 말굽 위치
- 초기 배치는 **가중 랜덤**으로 생성하되, **데드락 방지 보정**을 생성 단계에 넣는다 — 빨강 3개가 붙을 자리가 항상 존재해야 한다
- 클리어 후 곧바로 다음 스테이지로 이어진다 (연속 플레이)

## 7. 메타 레이어

```
타이틀 → 로비(목장) ⇄ 스테이지 셀렉트 → 퍼즐 판 → 구출 연출 → 다음 스테이지
            ↓
          도감
```

| 요소 | 내용 |
|---|---|
| **로비 (목장)** | 구출한 동물이 실제로 목장에 늘어난다. 시각적 보상 |
| **레벨** | 총 구출 수 기반. 로비 상단 게이지 |
| **도감** | 구출 / 미구출 동물 그리드 |
| **연속 플레이** | 클리어 시 다음 스테이지로 직행 |

### 구현하지 않는 것

미션 · 상점 · 재화(코인·젬) · 일일 보상 — 상용 F2P 메타 풀세트는 퍼즐 엔진보다 크다. **심사위원이 실제로 만질 범위**에 집중한다.

## 8. 아트 방향

- 카툰 스타일, 두꺼운 아웃라인, 채도 높은 원색
- 배경: 낮의 헛간 내부. 나무 프레임이 좌우 반사벽 역할을 겸한다
- 붉은말이 화면 하단에서 위를 올려다보며 타일을 던지는 자세 — 발사대가 곧 캐릭터
- **타일 아트 6종**(빨·노·초·파·보·황금) + 말굽 타일 + 부스터 아이콘 3종 + 케이지 + 동물

**제작 사양:** 육각 반지름 30px 기준 **셀 폭 52px**. 논리 해상도 430×800, 7열 배치.

## 9. AI 활용

인게임 런타임 LLM은 **사용하지 않는다.** 순수 규칙 게임이므로 억지 접목은 오히려 감점 요인이고, 오프라인 폴백·쿼터·지연이라는 시연 리스크만 늘어난다.

AI 활용은 **제작 과정 전체**로 증명한다:

- 게임 로직 소스코드 생성
- 이미지 에셋 생성
- 배경음악 생성
- 작업을 노드 스펙으로 분해해 에이전트에게 위임한 기록 → 그 모음이 곧 **에이전트 설계서**가 된다
