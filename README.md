# Red Horse Rescue 2026

> 육각형 슈터로 우리에 갇힌 동물을 구한다.
> 2026 병오년, 붉은말이 동료를 모은다.

**NHN GAME × AI 해커톤 2026 (NAN 2026) 본선 출품작**

- 공통 주제어 **2026년** — 병오년, 붉은 말의 해
- 기능 키워드 **물리법칙**(추첨) — 속도 · 중력 · 반사 · 빛과 색

## 무엇을 만들었나

버블 슈터의 조준·발사·벽 반사 감각 위에, **육각 격자와 멀티셀 케이지**를 얹은
퍼즐입니다. 타일을 터뜨리는 것 자체가 목적이 아니라 **갇힌 동물을 꺼내는 것**이
목적입니다.

같은 색 육각 타일이 셋 이상 맞닿으면 그 덩어리가 통째로 사라집니다.
발사체의 색은 **판에 남아 있는 색 중에서만** 뽑히므로 쓸모없는 탄이 없고,
발사 제한이 곧 난이도가 됩니다.

```
빨강 → 노랑 → 초록 → 파랑 → 보라 → 황금
```

여섯 색의 배열은 임의로 정한 순서가 아니라 **가시광선의 파장 순서**입니다.

### 우리와 구출

판 한가운데에 창살로 둘러싸인 큰 육각 우리가 박혀 있고, 그 둘레를 1칸짜리
타일 12개가 감쌉니다. 둘레는 **6면 × 2칸**이고, 이 중 **상단 한 면은 조건에서
빠집니다** — 발사대가 판 아래에 있어 그 자리는 조준으로 닿지 않기 때문입니다.

나머지 5면을 걷어내면 자물쇠가 풀리고 동물이 쏟아져 나옵니다.
빠진 상단 면은 사라지는 대신 **진행도 표시기**가 됩니다. 한 면이 열릴 때마다
금이 한 줄씩 늘어나므로, 카운터를 읽지 않아도 판만 보고 얼마나 남았는지 압니다.

우리는 천장에 매달려 있어 주변 타일이 저절로 무너지지 않습니다.
받침을 잃은 덩어리만 낙하하며, 그때 말굽이 회수됩니다.

## 실행

**Node 20~24 권장** (`.nvmrc`에 22 고정).

```bash
nvm use          # 또는 Node 22
npm install
npm run dev      # 개발 서버 — localhost:5173
npm run build    # 타입체크 + 프로덕션 빌드
npm test         # 유닛 테스트
npm run share    # 빌드 후 프리뷰 서버 (외부 공유용)
```

### 단일 파일 빌드

```bash
npm run build:single   # 단일 HTML (로컬 파일로 실행)
```

## 아키텍처

```
src/data/stages/*.json  →  src/engine/hex/  →  src/ui/hex/
      스테이지 정의         순수 TS · Pixi 0      Pixi 렌더
```

의존은 한 방향으로만 흐릅니다. `engine/`이 렌더러를 모르기 때문에 게임 규칙
전체가 헤드리스로 검증됩니다 — 화면이 없어도 한 판이 처음부터 끝까지 굴러갑니다.

| 계층 | 내용 |
|---|---|
| `engine/hex/` | 축좌표계 · 그리드 · 색 판정과 제거 · 낙하 · 궤적과 스냅 · 케이지 6면 분할 · 런 상태 · 부스터 · 스테이지 검증 |
| `ui/hex/` | 보드 렌더 · 케이지와 구출 연출 · HUD · 런처 · 화면 조립 |

| `tools/` | UI 배치 에디터 (`/ui.html`) |

## 화면 구성

전체는 16:9 가로지만 **게임은 세로 게임**입니다. 중앙 9:16 컬럼(450×800)
안에서만 놀고, 좌우 패널은 가로 화면을 채우는 헛간 장식입니다.

```
┌──────────────┬────────────┬──────────────┐
│   좌 패널    │   게임판   │   우 패널    │
│   175:288    │    9:16    │    175:288   │
└──────────────┴────────────┴──────────────┘
```

`9/16 + 2×(175/288) = 16/9` — 오차 0의 정확한 분할입니다.
좁은 세로 화면에서는 중앙 컬럼만 보이고 게임은 그대로 성립하므로,
**게임에 필요한 것은 좌우 패널에 두지 않습니다.**

## 에셋 파이프라인

디자이너가 `public/assets/` 아래에 파일을 드롭하면 코드 변경 없이 반영됩니다.
아직 도착하지 않은 슬롯은 색 육각·창살 프레임 같은 폴백으로 그려지므로,
아트가 하나도 없어도 게임이 성립하고 일부만 도착해도 정상 동작합니다.

제작 사양은 `docs/ART_SPEC.md`에 있습니다.
UI 배치는 브라우저 에디터 `/ui.html`에서 조정합니다 — 로비·인게임·설정창 탭이
한 페이지에 있고, 저장하면 `src/data/uiLayout.json`이 갱신됩니다.

## AI 활용

인게임 런타임 LLM은 사용하지 않습니다. 순수 규칙 게임이라 억지 접목은 시연
리스크만 늘립니다. AI는 **제작 과정 전체**에 쓰였습니다 — 게임 로직 생성,
이미지·음원 생성, 작업을 노드 스펙으로 쪼개 에이전트에게 위임한 기록.
