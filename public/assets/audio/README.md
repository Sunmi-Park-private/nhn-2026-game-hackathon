# 소리

`/ui.html` → **오디오** 탭에서 올린다. 파일 이름은 에디터가 정한다.

| 슬롯 | 파일 | 언제 |
|---|---|---|
| 로비 BGM | `bgm-lobby.mp3` | 로비에 들어갈 때 (반복) |
| 인게임 BGM | `bgm-stage.mp3` | 스테이지에 들어갈 때 (반복) |
| 발사 | `sfx-shot.wav` | 타일을 쏠 때 |
| 터짐 | `sfx-pop.wav` | 같은 색 셋이 사라질 때 |
| 구출 | `sfx-rescue.wav` | 우리가 열릴 때 |
| 클리어 | `sfx-clear.wav` | 스테이지 성공 |
| 실패 | `sfx-fail.wav` | 발사 소진 |
| 버튼 | `sfx-tap.wav` | 버튼을 누를 때 |

- **BGM은 mp3, 효과음은 wav**를 권한다. wav는 지연 없이 즉시 울린다.
- BGM은 **이음매 없이 반복**되게 잘라 준다. 앞뒤 무음이 있으면 한 바퀴마다 끊긴다.
- 볼륨은 코드가 BGM 0.5 · 효과음 0.8을 곱한다. 원본은 **피크에 맞춰 정규화**해 준다.
- 효과음은 설정창의 **SOUND**, 배경음악은 **MUSIC** 토글을 따른다.
- 파일이 없는 슬롯은 그냥 소리가 나지 않는다 — 게임은 정상 동작한다.
